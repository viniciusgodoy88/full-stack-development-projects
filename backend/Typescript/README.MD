# 📖 Sobre

Esta pasta contém projetos desenvolvidos para estudo de **TypeScript aplicado ao backend**, explorando conceitos fundamentais da linguagem e da programação orientada a objetos.

Os códigos foram criados com o objetivo de praticar:

- Tipagem estática
- Organização modular
- Classes e Interfaces
- Generics
- Namespaces
- Manipulação de objetos e estruturas de dados

Todos os exemplos foram implementados utilizando **Node.js + TypeScript**.

---

# 🧠 Conceitos Abordados

Durante os estudos nesta pasta foram praticados os seguintes conceitos:

### 🔹 TypeScript

- Tipagem estática
- Interfaces
- Classes
- Generics
- Namespaces
- Modules
- Prototypes
- Encapsulamento

### 🔹 Programação

- Programação Orientada a Objetos (POO)
- Estruturação de código
- Reutilização de código
- Modularização
- Injeção de dependência simples

# 📚 O que foi aprendido

Ao desenvolver os códigos desta pasta foi possível aprender:

✔ Como criar **interfaces e implementá-las em classes**

✔ Como usar **tipos genéricos (Generics)** para tornar classes reutilizáveis

✔ Como organizar projetos utilizando **modules e namespaces**

✔ Como aplicar **POO em TypeScript**

✔ Como criar métodos e manipular dados utilizando tipagem forte

✔ Como estruturar código backend de forma mais organizada

✔ Como aplicar **encapsulamento e injeção de dependência** em classes

✔ Como modelar **sistemas reais** (biblioteca, cursos, lâmpadas, e-mails) com TypeScript

# 🧪 O que é demonstrado nos códigos

## 1️⃣ Aula01 — Biblioteca e Curso

### Funcionalidades

- Modelagem de uma biblioteca com livros e autores
- Modelagem de um sistema de cursos com alunos e matrículas

### Conceitos aplicados

- Interfaces
- Classes e instâncias
- Tipagem estática
- Exportação de módulos

---

## 2️⃣ Aula02 — Programação Orientada a Objetos

### Funcionalidades

- Criação de objetos com propriedades e comportamentos
- Herança entre classes
- Métodos públicos e privados

### Conceitos aplicados

- Classes e construtores
- Herança (`extends`)
- Encapsulamento
- Prototype
- POO aplicada ao TypeScript

---

## 3️⃣ Aula03 — Generics

### Funcionalidades

- Classe genérica reutilizável para armazenamento tipado
- Funções genéricas com restrições de tipos

### Conceitos aplicados

- Generics (`<T>`)
- Restrições de tipos (`extends`)
- Tipagem avançada
- Reutilização de código

---

## 4️⃣ Aula04 — Operações Matemáticas

### Funcionalidades

- Soma, subtração, multiplicação e divisão
- Operações avançadas: exponenciação e módulo
- Composição de módulos separados por responsabilidade

### Conceitos aplicados

- Exportação e importação de módulos
- Namespaces
- Separação de responsabilidades
- Organização de código

---

## 5️⃣ Aula05 — Sistema de E-mail e Controle de Lâmpada

### Funcionalidades

- Simulação de envio de e-mail para novos usuários
- Registro de usuário no sistema
- Controle de estado de uma lâmpada (ligar e desligar)

### Conceitos aplicados

- Classes e encapsulamento
- Injeção de dependência simples
- Métodos de instância
- Organização de responsabilidades entre classes
- Interfaces comportamentais

# 📂 Estrutura do Diretório

```
backend/
│
└── Typescript/
    │

        └── lampada.ts         # Controle de estado de lâmpada (ligar/desligar)
```

# 🚀 Objetivo

O objetivo desta pasta é servir como **base de estudos para desenvolvimento backend utilizando TypeScript**, consolidando conceitos fundamentais antes de avançar para projetos mais complexos como:

- APIs REST com Express
- Frameworks como NestJS
- Integração com bancos de dados (PostgreSQL, MongoDB)
- Arquiteturas backend completas (Clean Architecture, DDD)
