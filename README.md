## 🔍 Destaques do Backend

### 🧩 Domain Driven Design — Aula02

API REST completa com arquitetura limpa e separação por domínio.

- TypeScript + Node.js + Express
- TypeORM + PostgreSQL + pg
- Autenticação JWT
- Repositórios por adapter (pg e TypeORM)
- Migrations, Entities, Use Cases e Factories
- Validação com Zod

### 🐦 stock_pettech_product — Aula06

Microserviço de estoque com NestJS, pronto para produção.

- NestJS + TypeScript
- MongoDB + Mongoose
- Docker + Docker Compose
- Prometheus (métricas)
- Swagger / ReDoc
- GitHub Actions (CI/CD)
- Guards, Interceptors, Pipes e Filters

## 🎯 Objetivos de Aprendizado

- Projetar e implementar APIs RESTful escaláveis
- Aplicar arquitetura limpa, MVC e Domain Driven Design
- Conectar serviços de back-end a bancos relacionais e NoSQL
- Containerizar aplicações com Docker
- Autenticar e autorizar usuários com JWT
- Monitorar serviços com Prometheus
- Automatizar pipelines com GitHub Actions
